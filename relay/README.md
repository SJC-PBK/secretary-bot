# 비서봇 PC 중계기

이 PC의 Claude Code 세션을 비서봇(scv)이 관리할 수 있게 이어주는 작은 상주 프로그램입니다. 관리자 전용입니다.

## 하는 일
- 1분마다 `C:\Users\jobcnt\projects` 아래 프로젝트별 최근 세션 현황을 비서봇으로 보냅니다.
- 10초마다 비서봇에 쌓인 지시를 가져와, 해당 폴더의 최근 세션을 이어서 실행하고 결과를 보냅니다.
- 파일 수정은 바로 하고, 커밋·push·삭제·서버 접속 같은 명령은 실행하지 않고 슬랙 승인 버튼으로 넘깁니다.
- 그 폴더 세션을 PC에서 쓰는 중(최근 3분 안에 기록 변경)이면 끝날 때까지 기다립니다.

## 슬랙에서 쓰는 법 (비서봇 DM)
- `클로드 코드 세션 현황 알려줘`
- `cafe-pos에 메뉴 화면 폭을 reports랑 같게 맞추라고 전해줘`

## 실행·중지
- 시작: `start-relay.vbs` 더블클릭 (창 없이 실행)
- 로그인 시 자동 시작: `start-relay.vbs` 바로가기를 시작프로그램 폴더(`Win+R` → `shell:startup`)에 넣기
- 중지: 작업 관리자에서 `node.exe`(명령줄 `relay.js`) 종료
- 로그: `relay.log`
- 설정: `.env` (서버 주소·공유 비밀값·대상 폴더 — 커밋 금지, 서버 `.env`의 `RELAY_SECRET`과 같아야 함)
