# 아이디어노트 — secretary-bot (개인 비서 봇)

작성일: 2026-08-13
상태: 확정 (→ 기획 완료)

## 목표 (한 문장)
슬랙에서 말을 걸면 내 업무를 도와주는 개인 비서 — 질문에 답하고, 문서·메일 초안을 써주고, 약속한 일을 때맞춰 알려준다.

## v1 핵심기능 3개
1. 대화형 질문답변 — 슬랙 DM으로 물으면 답변
2. 문서·메일 초안 작성 — 요청 시 공문/메일/요약 초안 생성
3. 리마인더·알림 — "언제 뭐 알려줘" 저장 후 때맞춰 슬랙 DM 알림

## 안 만들 것 (v1 제외)
- 반복 업무 자동화(GAS/AppSheet 실연동) → v2 보류
- 팀·다중 사용자 → 개인 비서로 시작 (제외)
- 홈페이지 코드작업·배포 → CC봇 담당 (역할 분리)

## 사용자 확정 설계 결정 (2026-08-13)
- 대화 방식: 슬랙 DM 1:1
- 데이터 접근: 접근 없음 (순수 대화·글쓰기만)
- 호스트: 사무실 서버(scv, 192.168.x.x) 한켠
- 리마인더: DM 1회성 (반복은 v2)
- 엔진: 헤드리스 Claude(`claude -p`) — 구독 활용, 호출당 API 비용 0
