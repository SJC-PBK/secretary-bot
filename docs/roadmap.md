## [현실안] (실현 가능성 높음 — v3 후보)
- **RAG(과거 대화·문서 전체 검색)** — 장기기억 ③단계. 임베딩/벡터 저장 필요. v3.
- **다중 사용자화** — userId 토대 있음. 캘린더는 워크스페이스 **서비스계정(도메인 위임)** 으로 승격, 두뇌는 직원별 클로드 계정 선택 가능.
- **hwpx 실제 문서 생성 연동** ★최우선 — 사용자가 이미 kordoc MCP·/gongmun·한글의 달인 도구를 쓰므로, "초안 텍스트"를 넘어 봇이 바로 hwpx 공문 파일을 만들어 DM으로 첨부하면 업무 효율 급상승. 데이터·비용 낮음.
- **홈페이지 데이터 조회** — 봇에 읽기 전용 조회를 주면 "이번 주 신규 구인공고 몇 건?" 즉답. 접근 범위 재평가(개인정보) 필요.
- **반복 리마인더** — "매주 월요일 보고" 등. 저장소에 recurrence 필드 추가 수준.
- **자주 쓰는 초안 템플릿 기억** — 사용자대표 호감 렌즈 산출.
