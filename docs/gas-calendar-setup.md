# GAS 캘린더 웹앱 배포 안내 (사장님 작업, 1회 · 폰 브라우저 가능)

비서봇이 내 구글 캘린더에 일정을 등록/조회/수정/삭제하려면, **내 계정으로 도는 작은 GAS 웹앱**을 한 번 배포해야 합니다. (봇은 이 웹앱 URL과 비밀토큰만 알고, 실제 캘린더 작업은 내가 소유한 이 GAS가 수행 — 봇은 구글 자격증명을 안 가짐.)

## 준비물
- 프로젝트의 `gas/Code.gs` 파일 내용 (이미 작성돼 있음)

## 단계
1. **script.google.com** 접속(내 구글 계정) → **새 프로젝트**.
2. 기본 `Code.gs` 내용을 지우고, 이 저장소의 **`gas/Code.gs` 전체를 붙여넣기** → 저장.
3. **스크립트 속성에 비밀토큰 설정:**
   - 왼쪽 **⚙ 프로젝트 설정** → 아래 **스크립트 속성** → **속성 추가**
   - 이름: `SHARED_SECRET`
   - 값: 임의의 긴 비밀 문자열(예: 40자 랜덤). **이 값을 기억/복사**해두세요.
4. **배포:** 오른쪽 위 **배포 → 새 배포** → 유형(⚙) **웹 앱** 선택
   - 설명: 아무거나
   - **실행:** 나(내 계정)
   - **액세스 권한:** **모든 사용자**  ← (봇이 호출할 수 있어야 함. 실제 보안은 SHARED_SECRET로)
   - **배포** → 권한 승인(내 캘린더 접근 동의) 창이 뜨면 승인
5. 배포되면 나오는 **웹 앱 URL** 을 복사(`https://script.google.com/macros/s/..../exec` 형태).

## 봇 서버에 넣을 값 (아침에 함께 / 또는 알려주시면 제가 설정)
서버 `.env`(`/srv/claude-bot/secretary-bot/.env`)에 두 줄 추가:
```
GAS_WEBHOOK_URL=<4번에서 복사한 웹앱 URL>
GAS_SHARED_SECRET=<3번의 SHARED_SECRET 값>
```
→ 봇 재시작하면 캘린더 기능이 켜집니다. (이 두 값이 없으면 봇은 "캘린더 연동이 아직 설정 전"이라고 안내하고 나머지 기능은 정상.)

## 주의
- **SHARED_SECRET**은 비밀번호입니다. 채팅에 붙이지 말고 파일/설정에만.
- 코드를 고쳐 재배포할 때는 **배포 관리 → 기존 배포 편집(연필) → 새 버전**으로 해야 **URL이 유지**됩니다(새 배포로 만들면 URL이 바뀜).
- 응답 키(id·title·start 등)는 봇 `app.js`가 기대하는 형식에 맞춰 `Code.gs`가 반환하도록 이미 정렬돼 있습니다.
