# 기획서 — secretary-bot

작성일: 2026-08-13
상태: 확정
원본: docs/idea.md

## 목표
슬랙에서 말을 걸면 내 업무를 도와주는 개인 비서 — 질문에 답하고, 문서·메일 초안을 써주고, 약속한 일을 때맞춰 알려준다.

## 기술 구성 (최종 목록)
- 화면: 없음 (슬랙 DM 텍스트 기반 — 별도 GUI 없음)
- 뼈대: Node.js + Slack Bolt (Socket Mode)
- 두뇌(엔진): 헤드리스 Claude (`claude -p`) — 도구 미부여(순수 텍스트)
- 저장: 파일 기반 JSON (리마인더·대화 맥락)
- 배포: 사무실 서버(scv, 192.168.0.97)에 `secretary-bot.service` (systemd) 상시 가동

### 선택 근거
- 뼈대(Bolt/Socket Mode): CC봇·투표봇과 동일한 검증된 방식, 공개 URL·포트 개방 불필요 → 보안·설정 간단. 차선책 파이썬을 안 고른 이유 = 기존 봇 2개가 모두 Node라 언어 통일이 유지보수에 유리.
- 두뇌(헤드리스 Claude): 호출당 API 비용 0(구독 활용), 질문답변·글쓰기 즉시 가능. 단점 = 순수 대화에도 몇 초 지연(수용). v1 "접근 없음"이라 파일·명령 도구를 아예 주지 않아 봇이 서버를 건드릴 수 없음.
- 저장(JSON 파일): 개인용 소규모엔 DB 불필요, 백업·확인 쉬움. 차선책 SQLite는 현 규모에 과함.

## 모듈 구조
- `app.js` : 진입점 (Bolt Socket Mode, 이벤트 라우팅)
- `lib/claude.js` : 헤드리스 Claude 호출 래퍼 (도구 미부여)
- `lib/auth.js` : 접근 통제 (허용 Slack ID)
- `lib/memory.js` : 대화 맥락 저장/로드
- `lib/reminders.js` : 리마인더 등록·조회·취소
- `lib/scheduler.js` : 도래 리마인더 발송
- `data/` : reminders.json, 대화 맥락 (gitignore)
- `.env` : 토큰 (gitignore)
