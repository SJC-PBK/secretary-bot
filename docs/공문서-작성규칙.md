# 📝 내부 공문·기안 작성 규칙

> 비서봇(장비서)이 학습한 우리 기관 기안 작성 스타일입니다.
> 원본 규칙: `lib/claude.js`의 `GONGMUN_STYLE`(채팅 md 초안) + `buildDocSpec` ⑤(hwpx 생성).
> 같은 내용이 Claude Code 스킬 **`내부공문작성`** 으로도 등록돼 있습니다.

---

## 1. 문서 뼈대

```
제목: ○○○ 구매(계약) 계획

○○○을 위해 △△△을 구매하고자 합니다.

1. 목적: …
2. …
…

붙임  1. ○○ 1부.
      2. ○○ 1부.  끝.
```

- **첫 줄**: `제목: ○○` → 한 줄 띄움
- **도입문**: 배경·목적을 요약한 한 문장(`~하고자 합니다.` / `~보고드립니다.`) → 한 줄 띄움
- **본문**: 번호 항목
- **마지막**: 붙임 + `끝.`
- 코드블록, `기안문`·`기안부서`·`기안일자` 같은 서식 라벨은 넣지 않는다(본문만).

## 2. 항목 번호 계층

| 단계 | 기호 | 들여쓰기 |
|---|---|---|
| 1단계 | `1.` `2.` | 없음 |
| 2단계 | `가.` `나.` | 공백 1칸 |
| 3단계 | `1)` `2)` | 공백 2칸 |
| 4단계 | `가)` `나)` | 공백 3칸 |

- `□ ○ -` 기호는 **쓰지 않는다**.
- 값이 하나인 항목은 **인라인**: `N. 라벨: 값`
  - ✅ `1. 목적: 직원 대외활동용 명함 제작`
  - ❌ `1. 목적` / `2. 직원 대외활동용 명함 제작` (라벨과 값이 번호를 따로 먹는 오류)
- 세부가 여러 개인 항목만 하위(`가.`/`나.`)로 내린다.

## 3. 금액·날짜 표기

- 금액: 아라비아 숫자 + 한글 병기, 부가세 포함 여부 명시
  - 예: `금5,945,500원(금오백구십사만오천오백원, 부가세 포함)`
- 날짜: `2026. 8. 31.` (요일 필요 시 `2026. 9. 15.(화)`)

## 4. 소요예산 (필수 항목)

- 항상 **부가세 포함 최종 총액을 먼저** 쓴다: `N. 소요예산: 금○○원(금○○원)`
- 재원·용도가 둘 이상이면 아래에 세부별 합계를 쓰고, **각 세부마다 산출내역 표**를 붙인다.

```
5. 소요예산: 금5,945,500원(금오백구십사만오천오백원)
 가. 카페 가구: 금3,850,000원(금삼백팔십오만원)

| 품목 | 규격(모델명) | 산출금액(원) | 금액(원) |
|---|---|---|---|
| 테이블 | ○○ | 350,000×5 | 1,750,000 |
| 의자 | ○○ | 175,000×10 | 1,750,000 |
| 소계 | | | 3,500,000 |
| 부가세 10% | | | 350,000 |
| 합계 | | | 3,850,000 |

 나. 사무 가구: 금2,095,500원(금이백구만오천오백원)
 (같은 형식의 표)
```

## 5. 예산과목·자금원천

- 예산과목이 하나면 인라인: `6. 예산과목: 운영비-일반운영비-사무관리비(일반수용비)`
- 품목별로 다르면 매핑 표:

```
6. 예산과목 및 자금원천: 민간위탁금

| 품목 | 예산과목 |
|---|---|
| 카페 가구 | 사업비-○○-○○ |
| 사무 가구 | 운영비-○○-○○ |
```

- 자주 쓰는 항목명: 소요예산 / 예산과목(예산항목) / 자금원천(예: 민간위탁금) / 결제방법(계좌이체) / 구매(공사) 업체(사업자등록번호)

## 6. 표

- 품목·산출·예산 내역은 **반드시 표**로 정리한다(텍스트 나열 금지).
- 산출표 열: `품목 | 규격(모델명) | 산출금액(원) | 금액(원)` + 마지막 `소계 / 부가세 10% / 합계` 행.

## 7. 줄 간격

- 도입문 뒤, 붙임 앞: 한 줄 띄움
- 하위(`가.`/`나.`)가 딸린 항목 뒤: 한 줄 띄움
- 한 줄짜리 항목끼리는 붙여 쓴다

## 8. 붙임과 "끝."

- `붙임` 뒤 **공백 2칸** 후 첫 항목: `붙임  1. 견적서 1부.`
- 붙임이 여러 개면 줄을 바꿔 `2. ○○ 1부.` 로 나열
- **"끝."은 항상 문서 맨 마지막 내용의 온점 뒤 공백 2칸 다음에** 온다
  - 붙임 있음: `3. 청렴계약이행서약서 1부.  끝.`
  - 붙임 없음: `6. 비고: 구매 후 비품 등록.  끝.`
- 본문에서 첨부를 가리킬 땐 `※붙임1` 처럼 표기

## 9. 사실 지키기

- 모르는 값(날짜·장소·금액·업체·연락처)은 지어내지 말고 `[ ]` 또는 `○○`로 비운다.
- 계산은 소계 → 부가세 10% → 합계 순으로 검산한다.

## 전체 예시

```
제목: 카페 운영용 가구 구매 계획

카페 훈련장 리모델링에 따라 노후 가구를 교체하고자 다음과 같이 구매하고자 합니다.

1. 목적: 훈련생 실습 환경 개선 및 노후 가구 교체
2. 구매 업체: ○○가구(사업자등록번호 ○○○-○○-○○○○○)
3. 구매 일정: 2026. 9. 30.까지
4. 소요예산: 금3,850,000원(금삼백팔십오만원, 부가세 포함)

| 품목 | 규격(모델명) | 산출금액(원) | 금액(원) |
|---|---|---|---|
| 테이블 | ○○ | 350,000×5 | 1,750,000 |
| 의자 | ○○ | 175,000×10 | 1,750,000 |
| 소계 | | | 3,500,000 |
| 부가세 10% | | | 350,000 |
| 합계 | | | 3,850,000 |

5. 예산과목: 사업비-○○-○○
6. 자금원천: 민간위탁금
7. 결제방법: 계좌이체

붙임  1. 견적서 1부.
      2. 사업자등록증 1부.
      3. 청렴계약이행서약서 1부.  끝.
```
