## 아침 할 일 (순서대로)

### 1단계 — GAS 웹앱 배포 【사장님, 폰 브라우저 가능】
→ `docs/gas-calendar-setup.md` 그대로 따라 하기.
결과물 2개 확보: **웹앱 URL**, **SHARED_SECRET 값**. (채팅에 붙이지 말고 갖고 계시기)

### 2단계 — 서버에 v2 반영 【사무실 PC에서 — 서버는 사내망 전용이라 여기서만 됨】
제가(이 세션 재개해서) 아래를 실행하면 됩니다. 순서:
1. 서버 `.env`(`/srv/claude-bot/secretary-bot/.env`)에 두 줄 추가:
   `GAS_WEBHOOK_URL=<1단계 URL>` / `GAS_SHARED_SECRET=<1단계 secret>`
2. v2 코드 5파일 서버로 복사(app.js, lib/claude.js, lib/profile.js, lib/session.js, lib/calendar.js) — 새 npm 의존성 없음(내장 fetch 사용).
3. `sudo systemctl restart secretary-bot` → `journalctl -u secretary-bot -n 15` 로 "Now connected to Slack" 확인.

### 3단계 — 실테스트 (슬랙 DM) 【사장님】
- 캘린더: `내일 오후 3시 사인물 업체 방문 일정 넣어줘` → `내 일정` → `2번 삭제` / `2번을 오후 4시로 바꿔줘`
- 장기기억: `나는 공문을 개조식으로 선호해 기억해둬` → 이후 초안 요청 시 반영되는지 → `내 기억 보여줘` → `1번 잊어`

## 폰(출근길)에서 이어가기
- **가장 쉬운 유용한 일 = 1단계 GAS 배포**(브라우저라 폰으로 됨).
- **클로드 리모트**로 코드 손보려면: GitHub 저장소가 있어야 함(현재 로컬 커밋만). 아침에 저장소 만들고 push하면 브랜치 **main** 선택해 리모트 가능. ⚠️ 단 리모트(클라우드)는 **사무실 서버에 못 닿음** → 서버 반영·테스트는 사무실 PC에서.
- 이 대화 그대로 이어보려면(사무실 PC): `claude -r ca115b37-fdc3-47eb-84fd-57e7c16f8267`

## 알아둘 것 / 주의
- 서버 claude 인증 = `CLAUDE_CODE_OAUTH_TOKEN`(claudebot 구독, CC봇과 공유). 인터랙티브 로그인 불필요.
- v2 캘린더 삭제/수정의 query 검색은 **이번 주 범위**만(그 밖은 "내 일정"으로 번호 지목). 필요하면 확장 가능.
- 장기기억은 **완전 동일 중복만** 걸러 저장(상한 200) — 실사용 보며 조정 가능.
- v2는 **결재 사안**(내 캘린더 쓰기 + 프로필 저장) — 3단계 실테스트로 사장님이 직접 확인한 뒤 "완성"으로 간주. 그때까지 저는 "된다"고 하지 않습니다.
- 미검증: 캘린더 CRUD·장기기억 실동작, GAS 응답 키 실제 일치(app.js에 맞춰 작성했으나 첫 호출 시 한 번 확인 권장).
