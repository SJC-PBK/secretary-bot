# 🤖 비서봇 업데이트 내역

> 복잡하거나 중요한 작업은 문장 끝에 **-o** 를 붙이면 더 정교하게 처리합니다.
> (예: `사업계획 초안 잡아줘 -o`)

- **리마인더**(정한 시각에 알림) 추가
  ㄴ 예: "내일 오후 2시에 사인물 업체 미팅 있다고 알려줘"
- **구글 캘린더 연동**(개인 일정) 추가
  ㄴ 예: "다음 주 수요일 3시 업체 방문 일정 등록해줘"
- **장기기억**(내 정보·취향을 기억) 추가
  ㄴ 예: "나는 보고서를 개조식으로 선호해, 기억해둬"

## 8월 17일
- **다른 직원도 사용 가능** (신청 → 관리자 승인) 추가
  ㄴ 예: 비서봇에게 처음 말 걸면 자동으로 사용 신청됩니다
- **똑똑한 답변(-o)** 추가 (복잡한 일은 -o)
  ㄴ 예: "이번 분기 사업계획 초안 잡아줘 -o"
- **한글(hwpx) 공문 만들기** 추가 (기안문·보고서·계획서·통지 등)
  ㄴ 예: "직원 정보보안 교육 실시 알림 공문 만들어줘"
- **기관 기본 서식** 자동 적용 (본문 굴림체 13pt)
- **구글 문서·시트 만들기** (드라이브에 저장) 추가
  ㄴ 예: "이번 주 당직표를 구글 시트로 만들어줘"

## 8월 18일
- **구글 슬라이드(발표자료) 만들기** 추가
  ㄴ 예: "하반기 사업계획을 발표자료 슬라이드로 만들어줘"
- **회의록 작성** 추가 (전사본을 붙여넣으면 정리)
  ㄴ 예: 회의 녹취 텍스트를 붙여넣고 "회의록으로 만들어줘"
- **기존 한글 문서 수정** 추가 (hwpx 파일 올려서 고치기)
  ㄴ 예: hwpx 파일 올리고 "일시를 8월 25일로 바꿔줘"
- **구글 드라이브 검색·사본** 추가 (원본은 손대지 않고 사본만)
  ㄴ 예: "드라이브에서 2026 사업계획 찾아줘" → "1번 사본 만들어줘"
- **NAS(공유폴더) 검색·사본** 추가 (사본을 구글 드라이브로)
  ㄴ 예: "NAS에서 주간회의 자료 찾아줘" → "3번 드라이브로 가져와줘"
- **센터 공유 캘린더 등록** 추가
  ㄴ 예: "8월 25일 오전 10시 전체 회의를 센터 일정으로 등록해줘"
- **웹 검색**(최신 정보 답변) 추가
  ㄴ 예: "요즘 장애인 고용 관련 최신 정책 뉴스 정리해줘"
- **응답을 스레드로 + 진행 표시** (지금 작업 중인지 보임) 개선

## 8월 19일
- **할 일 목록**(마감일 포함) 추가
  ㄴ 예: "금요일까지 견적 확인, 할 일에 넣어줘" / "할 일 목록 보여줘" / "1번 완료"
- **아침 브리핑** 추가 (평일 아침, 오늘 일정·할 일을 자동 요약 DM)
  ㄴ 예: 아침에 자동으로 옵니다. 아무 때나 "오늘 브리핑"
- **회의 내용 → 할 일 자동 추출** 추가
  ㄴ 예: 회의 내용을 붙여넣고 "여기서 할 일 뽑아서 목록에 넣어줘"
- **이메일 읽기·작성·발송** 추가 (확인 후 발송 / 관리자용)
  ㄴ 예: "sjc 메일 확인해줘" → "2번 메일에 답장 써줘" → 확인 후 "메일 보내기 확인"

## 8월 20일
- **관리자 승인 편의 개선** (사용 요청 알림에서 **버튼 탭**으로 승인/거절 — 모바일에서 간편)
- **이메일 기능 활성화** (위임 메일함 연결 완료 — 관리자용)
- **첨부 파일 읽기 개선** (텍스트 파일·이미지 첨부, 파일 **링크(URL)** 로 줘도 내용을 읽음)
  ㄴ 예: 전사 .txt를 올리거나 링크를 붙이고 "회의록으로 만들어줘"
- **명함 → 연락처 정리** (명함 사진에서 이름·전화·이메일·회사 추출 → **vCard 파일** + **구글 주소록** 저장)
  ㄴ 예: 명함 사진 첨부하고 "이 명함 주소록에 저장해줘"
- **구글 설문지 만들기**
  ㄴ 예: "직원 만족도 설문지 만들어줘" → 편집·응답 링크

## 8월 21일
- **길찾기 (예상 소요시간·거리)** — 출발지→목적지, **대중교통** 기준(자동차도 가능)
  ㄴ 예: "센터에서 서울시청까지 얼마나 걸려?" ("센터"는 자동으로 회사 주소로 인식)
- **음성 → 텍스트 변환 + 회의록 자동정리** — 슬랙에 음성 파일을 올리면 서버에서 전사 후 회의록으로 정리
  ㄴ 시간이 걸려서(분량에 비례) **"완료되면 알려드릴게요"** 안내 후 백그라운드 처리 → 끝나면 스레드로 **회의록 + 전사본(.txt)** 전달
  ㄴ 예: 회의 녹음 파일 첨부 → 잠시 후 정리된 회의록 도착
- **이미지(사진) 내용 이해** — 글자 없는 사진도 봇이 보고 이해해서 활용
  ㄴ 예: 물건 사진 첨부 → "이 사진 보고 공지글 써줘"
- **(관리자 전용) 아침 브리핑에 서버 상태 + AI 토큰 사용량 리포트** — 매일 통계로 저장(구독 근거자료용)

## 8월 24일
- **할 일 목록 순서 이동·문구 수정** — 번호로 순서를 바꾸거나 내용을 고칠 수 있어요
  ㄴ 예: "14번을 6번으로 옮겨줘"(나머지는 자동으로 밀림), "6번을 ○○로 수정해줘"
- **내 "기억 문서" (구글 문서)** — 승인되면 내 구글 드라이브에 개인 기억 문서가 생겨요(나만 열람)
  ㄴ ①페르소나(응대 지침) ②장기기억(프로필 사실) ③최근 대화 메모리(보기 전용)를 담고,
  ㄴ 문서에서 ①②를 고친 뒤 "내 기억 문서 반영해줘"라고 하면 봇에 저장돼요. 열기: "내 기억 문서 보여줘"
- **할 일 목록 ↔ 구글 Tasks 완전 연동** — 슬랙 할 일이 폰 구글 Tasks("내 할일")와 같은 데이터가 돼요
  ㄴ 슬랙에서 추가/완료/이동/수정 → 폰에 즉시 반영, 폰에서 체크 → 슬랙에도 반영
- **마인드맵 자동 생성** — 주제나 회의 내용을 주면 사내 마인드맵으로 만들어 링크로 공유
  ㄴ 예: "이 회의록으로 마인드맵 만들어줘" / "하반기 사업계획 마인드맵으로 정리해줘" → 링크(전 직원 열람)
- **투표·룰렛 자동 게시(투표봇 연동)** — 채널을 지정하면 비서봇이 투표봇으로 대신 올려줘요
  ㄴ 예: "#점심 채널에 점심 메뉴 복수선택 투표 올려줘" / "#회의 채널에 발표 순서 룰렛 돌려줘"
  ㄴ 올릴 채널을 꼭 #채널명 으로 넣어주세요(비공개 채널은 그 채널에 투표봇 초대 필요)
